USINA

ALPHA · v0.2.0-alpha.1 in preparation
A synthesizer in the Ruído family. FM synthesis, physical modelling and audio processing: waves, resonating objects, noise and recordings of your surroundings.

Português · Install · Manual · Alpha notice · Web edition

Start with a sound

Use waves, resonators and recordings as sources or processing within the algorithm. Six operators combine synthesis and processing; CABINE and PLAY provide performance controls.

Start with a preset and explore its macros. You do not need to understand FM synthesis to begin. When you want to build a sound, the same instrument opens up algorithms, envelopes, filters and modulation routes.

View What it offers
SYNTH Six operators, algorithms and a connection matrix, filters and envelopes
FX Effects in FX A, FX B, AUX and LOOP INSERT
SEQ Notes, percussion and four modulation lanes
CABINE Routes, sounds, gestures, rhythms and performance actions, on screen or with a controller
PLAY Manuals or a grid, four macros, macro snapshots and XY movement

See the manual for this edition's features and limits. Explore a selection of sounds.

GitHub's automatic “Source code (zip/tar.gz)” contains this showcase repository, not the plugin's complete source. Use the source attachment named in the release notes. It must correspond to the same binary release.

Experimental Linux packages are deferred and are not included in this edition. Each release identifies the systems and formats actually tested. Check that your DAW supports your chosen format. No macOS package is offered yet. The separate Usina web edition can be explored in a browser, including on a Mac; features and MIDI access differ.

Installation and troubleshooting · Release notes

This is an alpha

Crashes, stuck notes, unexpected sounds and changes between versions are possible. Back up your projects. Start quietly: microphone input and feedback can become very loud. The output guard cannot control your headphone or speaker volume. Rehearse with the same version and equipment before performing live.
