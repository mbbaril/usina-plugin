# USINA

**ALFA · v0.2.0-alpha.1 em preparação**  
Um sintetizador da família **Ruído**. Síntese FM, modelagem física e processamento de áudio: ondas, objetos que ressoam, ruído e gravações do que está ao redor.

[English](README.en.md) · [Baixar e instalar](INSTALL.md) · [Manual](manual/README.md) · [Aviso do alfa](ALPHA.md) · [Versão web](https://usina.ruido.art.br/)

## Comece pelo som

Use ondas, ressonadores e gravações como fontes ou processamento dentro do algoritmo. Seis operadores combinam síntese e processamento; CABINE e PLAY oferecem controles de performance.

Você pode começar por um timbre pronto e explorar as macros. Não precisa conhecer síntese FM para dar o primeiro passo. Quando quiser construir por dentro, o mesmo instrumento abre algoritmos, envelopes, filtros e rotas de modulação.

| Vista | O que oferece |
|---|---|
| SYNTH | Seis operadores, algoritmos e matriz de ligações, filtros e envelopes |
| FX | Efeitos em FX A, FX B, AUX e LOOP INSERT |
| SEQ | Notas, percussão e quatro pistas de modulação |
| CABINE | Rotas, sons, gestos, ritmos e ações de performance, na tela ou com controlador |
| PLAY | Manuais ou grade, quatro macros, instantâneos de macros e movimento XY |

Consulte o [manual](manual/README.md) para os recursos e limites desta edição. [Conheça alguns timbres](SOUNDS.md).

## Baixar

**Os arquivos desta versão ainda estão em preparação. Esta página não anuncia um release disponível.**

Quando o release estiver publicado, abra **Releases → v0.2.0-alpha.1 → Assets** e escolha:

| Seu sistema | Arquivo | Conteúdo previsto |
|---|---|---|
| Windows 10/11, 64 bits | `Usina-0.2.0-alpha.1-windows-x64.zip` | VST3, CLAP e aplicativo Standalone |
| Fontes correspondentes | `Usina-0.2.0-alpha.1-fontes.zip` | Código completo e instruções para construir aquela versão |
| Verificação dos arquivos | `SHA256SUMS.txt` | Somas dos anexos |

**“Source code (zip/tar.gz)” automático do GitHub é a árvore desta vitrine. Não é o pacote completo de fontes do plugin.** Baixe o anexo de fontes indicado nas notas. Ele deve acompanhar os binários da mesma versão.

Linux experimental fica para uma entrega posterior e não acompanha esta edição. A confirmação dos formatos e sistemas efetivamente testados acompanha o release. Confira se sua DAW aceita o formato escolhido. **macOS ainda não é oferecido.** Para experimentar no navegador, inclusive em Mac, há o [Usina no navegador](https://usina.ruido.art.br/); ele é uma edição separada, com diferenças de recursos e de acesso MIDI.

## É um alfa

Pode travar, deixar notas presas, produzir sons inesperados ou mudar entre versões. Salve cópias dos projetos. Comece com volume baixo: microfone e realimentação podem gerar sons muito altos. A guarda de saída não controla o volume dos seus fones ou caixas. Antes de usar ao vivo, ensaie com a mesma versão e o mesmo equipamento.

Software livre, **sem garantia**. Leia o [aviso completo](ALPHA.md). O plugin não coleta dados nem se conecta à internet; links só abrem o navegador por escolha sua. Ao visitar o GitHub ou a versão web, aplicam-se também as condições desses serviços.
