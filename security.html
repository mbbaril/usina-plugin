Segurança / Security

Português

Para relatar uma possível vulnerabilidade, use Report a vulnerability na área de segurança do repositório. Não publique detalhes de exploração em uma Issue.

Inclua a versão, o sistema, passos para reproduzir e o impacto observado. Compartilhe apenas os arquivos necessários, sem dados pessoais ou credenciais.

O relato privado será habilitado no lançamento público. Se a opção ainda não estiver disponível, envie o relato para contato@ruido.art.br. Não há prazo garantido de resposta ou correção. Esta edição é alfa; a manutenção prioriza a versão mais recente e não garante atualizações para versões anteriores.

English

Report a suspected vulnerability through Report a vulnerability in the repository security area. Do not publish exploit details in an Issue.

Include the version, operating system, reproduction steps and observed impact. Share only necessary files, without personal data or credentials.

Private reporting will be enabled at public launch. If the option is not available yet, email contato@ruido.art.br. Response or fix times are not guaranteed. This is an alpha; maintenance prioritizes the latest version and does not guarantee updates to older versions.
